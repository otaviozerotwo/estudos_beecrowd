### O que entra?

* um valor inteiro (N)
* N valores

### O que sai?

- para cada N valor, imprimir se:
   * par - EVEN
   * ímpar - ODD
   * positivo - POSITIVE
   * negativo - NEGATIVE
   * zero - NULL

### Quais regras existem?

* a mensagem é em inglês e UPPERCASE
* cada valor pode ter mais de um tipo atrelado
* para cada valor uma linha com o retorno
* caso tenha mais de um tipo por valor, separar por um espaço

### Exemplo manual

valores: [-5, 0, 3, -4]

valor = -5
tipos = ODD NEGATIVE

valor = 0
tipos = NULL

valor = 3
tipos = ODD POSITIVE

valor = -4
tipos = EVEN NEGATIVE

### Quais variáveis preciso?

n = quantidade de valores a serem recebidos  
valores[] = array com tamanho n para armazenar os valores  
tipos[] = array para armazenar os tipos de cada valor  

### Qual padrão?

   ( ) Contagem  
   ( ) Soma  
   ( ) Busca  
   ( ) Maior/Menor  
   ( ) Repetição  
   (X) Transformação  
   (X) Classificação
