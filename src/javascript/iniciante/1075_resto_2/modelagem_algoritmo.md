### O que entra?

* um valor inteiro (N)

### O que sai?

* todos os números entre 1 e 10000 que divididos por N dão resto igual a 2

### Quais regras existem?

um valor por linha

### Exemplo manual

N = 13  

(1 % 13) === 2: não  
(2 % 13) === 2: sim  
(3 % 13) === 2: não
...

### Quais variáveis preciso?

n = divisor  
i = iterador do loop  
resultado = array para armazenar os valores obtidos do cálculo  

### Qual padrão?

   ( ) Contagem  
   ( ) Soma  
   ( ) Busca  
   ( ) Maior/Menor  
   (X) Repetição  
   ( ) Transformação  
   ( ) Classificação
